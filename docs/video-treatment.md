# 《毕业第一站》产品介绍片方案

## 目标

- 比赛评委在前8秒知道问题不是“缺少城市榜单”，而是“依赖了未经验证的判断”。
- 90秒内讲清产品为何存在、如何工作、Agent 为什么必要、它明确不承诺什么。
- 视觉抓人，但每个高光镜头都服务于产品逻辑。最终输出16:9、1080p、总时长小于2分钟。

## 核心表达

> 毕业第一站不替你选一座城。它把两种都可能成立的生活放在同一座站台上，找出最可能改变决定的那条信息。

事实边界：城市资料只能提供行业、活动、租金和气候线索，不能预测 offer、WLB、薪资或幸福。视频不出现“最适合”“准确率”“AI 算出赢家”等表述。

## 参考手法

2026-09-28 的 Manus 2.0 官方产品片时长2:46。可借鉴的是：极短命题字幕、真实产品画面、功能结果快速切换、角色群像作为情绪记忆点，以及“一句话 → 产品动作 → 可见结果”的节奏。这里不复制 Manus/Cue 的角色、字体、版式或镜头，只采用这些通用叙事方法。

## 视觉系统

- 原创近未来工业车站，深海军蓝背景；深圳轨道用冷青，杭州轨道用洋红，风险提示用信号黄。
- 黑猫与白狗是站台引导员。造型圆润、动作克制，承担“看发展线 / 看生活线”的轻量角色，不替用户决策。
- 产品 UI 必须来自真实 v0.6 截图。生成式画面只用于开场、转场和视觉隐喻，避免让模型伪造界面。
- 中文主标题每屏不超过14字；事实或限制用小字，只保留观众能读完的一句。
- 不在生成式画面内要求模型绘制中文；所有文字后期叠加，避免乱码。

## 旁白全文

毕业选城市，真正难的不是没有选择，而是每个选择都像对的。

“深圳成本低、机会多”“成都好玩、压力小”——这些通常不是结论，而是我们还没验证的判断。

所以，我们做了《毕业第一站》。先把行业、兴趣、预算和气候红线装上车。系统只负责缩小范围，最后两座城市，由你亲手留在同一座站台。

接着，用三幕看两种生活：第一份工作，普通下班后，以及真正住下去的代价。每一幕都把可核验事实、编辑判断和未知分开。看不出来，也是一条有效答案。

它会直接指出反例。比如，“深圳成本更低”缺少当前同口径支持；泛 AI 资料不能证明具身智能机会；湿度资料缺失，也不能算健康红线已经通过。

当三幕还没有答案，系统 Agent 不替你投票，也不改排序。它只提出一个最可能改变决定的问题。任务只有在你确认后，才会进入核验清单。

最后，你亲自选择先验证哪座城。另一座仍然保留。带走的不是“最适合”的答案，而是下一步去查的岗位、房源和真实日常。

毕业第一站。先验证，再出发。

## 声音

- 旁白：年轻、可信、略带笑意，不用广告腔；每分钟约190–210字。
- 音乐：90–110 BPM，轻电子木琴/拨弦加低频列车脉冲；不使用知名作品或平台示例音乐。
- 声效：出票、积木吸附、信号灯、盖章、列车离站五组短声效。Agent 出场不使用夸张“AI 神迹”音效。

## 验收

- 1920×1080，16:9，H.264/AAC，时长 `< 120s`。
- 第8秒前说清问题，第28秒前出现真实产品，第74秒前说清 Agent 边界。
- 至少出现三段真实 v0.6 UI，生成式 UI 不作为功能证据。
- 没有乱码、错误城市数据、幸福/录取预测或未经验证的上架表述。
- 关闭声音仍能看懂主线；只听声音也能理解产品价值。
