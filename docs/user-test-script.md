# 双城版首轮真人试玩脚本

目标是判断产品是否帮助用户看见自己的假设和下一步行动，不评估“推荐准不准”。每位15–20分钟，主持人不解释按钮，不替用户选择，也不提示预期答案。

## 统一开场

> 这是一个还在测试的城市决策工具。它不会替你决定去哪，也不会预测你会不会幸福。请按你现在真实的想法使用，过程中想到什么就说什么。看不懂、不同意或觉得不像你，都比顺利点完更有价值。

记录开始前只确认：参与者允许本次记录用于产品改进；若不同意录音，就只做匿名文字笔记。

## 小陈场景

让小陈从“我已经在纠结几座城”进入，自行带入现实候选。主持人只在停滞超过30秒时说：“按你现在的理解继续就好。”

重点观察：

- “具身智能行业”是否被准确表达，还是仍让他感觉被泛 AI 替代；
- 4000元预算看到城市级租金基准时，他如何理解“压力”与“住得起”；
- 湿度从普通偏好变成健康红线后，是否改变他看深圳与杭州的方式；
- 看到“深圳成本低”证据不足时，是觉得被纠正、被帮助，还是被工具抬杠；
- 决胜问题是否真的比再看一张总分表更值得行动。

结束后只问：

1. 你刚才最依赖、但现在发现还没证实的一句话是什么？
2. 哪一幕最像你真实的纠结？哪一幕完全不是？
3. 接下来七天内，你会先做哪一个核验动作？
4. 什么新信息会让你改选另一座城？

## 小雷场景

让小雷自行带入上海、杭州、成都或她当下真实候选，不要求保持旧档案。

重点观察：

- 游泳、健身与演出是否能被表达成“会重复发生的日常”，而不是泛兴趣标签；
- 8000元预算覆盖城市级基准后，是否停止制造虚假优势；
- “成都好玩、压力小”被拆成活动、岗位与公司条件时，她是否仍觉得产品理解她；
- 上海的已知机会/演出线索与气候/节奏代价是否形成真实冲突；
- 决胜问题是否落到可执行的岗位、团队、活动或生活半径核验。

结束后沿用四个问题，不询问“推荐得准不准”。

## 成功标准

每位参与者至少满足以下三项中的两项，且没有出现严重误导：

1. 能用自己的话说出至少一条原本依赖的假设；
2. 发现至少一个此前没有意识到的信息缺口；
3. 能说出一项具体、可执行的现实核验动作。

严重误导包括：把城市级租金理解成目标岗位旁一定租得到；把产业线索理解成个人录用概率；把城市标签理解成 WLB；把资料未知理解成红线已通过。

## 主持人记录规则

- 记录原话和发生在哪一幕，少写总结性形容词。
- 区分“界面没看懂”“事实不同意”“价值排序不同”“资料缺失”。
- 不把用户点了某城解释成产品预测成功。
- 单次选择不升级为普遍结论；两人都遇到的同一问题，才进入下一版优先级讨论。
