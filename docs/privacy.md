# 资料与隐私说明

适用版本：城市红娘 v0.2.0。更新：2026-10-03。

## Web 体验版

应用不需要账号，填写的资料、问答和进度保存在当前浏览器的 localStorage。当前 Web 版没有分析统计、远端表单接口或模型请求。服务仅监听本机回环地址，并只提供页面运行所需的公开文件，不提供原生存档、日志或审核资料。

通过页面底部“本机资料 → 清除本机资料 → 确认清除”可以删除本浏览器中保存的资料。清除浏览器站点数据也会移除进度。共用设备上的其他使用者可能访问尚未清除的资料。

保存的分享车票和复制摘要包含候选城市与生活关键词，默认不包含昵称、年龄、院校、预算或欣赏的人的信息。主动发出的图片或文字由接收平台按其规则处理。

## OctoScript 原生版

资料由宿主的应用本地存储保存，可以在应用中清除。核心撮合使用本地规则，不需要模型。

只有点击“让 Agent 提出修改”，应用才请求宿主的系统 Agent。请求包含你输入的自由反馈、行业、工作与生活取舍、兴趣与最重视的兴趣、气候避开项和硬条件、已排除城市、候选城市及其依据、代价、待核验事项和资料版本。待核验事项可能包含房租上限。

应用不会自动附带结构化档案里的昵称、学校、年龄、具体岗位文本、MBTI／星座或欣赏对象资料。**自由反馈会原样发送，因此请勿在这段话中填写姓名、学校、密钥或其他隐私。** 宿主及其配置的模型服务决定请求的进一步处理方式，使用前应查看相应服务的隐私说明。

模型返回的修改只是待确认建议。点击“确认修改并重新匹配”后，应用才更新允许修改的偏好、重排并保存。可以拒绝建议；格式不符、过期或失败的响应不会修改资料。已有城市排除和气候底线不会被模型撤销。

本应用不将自由反馈原文、未确认建议或完整模型响应写入自己的存档。确认后保存新的偏好、资料版本和执行变化说明。宿主的 Agent 会话历史及模型服务可能另外保留请求或响应；清除本应用资料不会自动清除这些外部记录。

card-host 环境不提供系统 Agent 服务。真实模型的验收状态见 [公开版本说明](publication.md)，不能将测试响应或不可用提示视为模型已接通。

## 外部链接与反馈

打开城市来源或 GitHub 链接后，相应网站可能按其隐私规则处理访问。报告问题时请不要公开真实个人档案、密钥或他人隐私；合成资料通常足够复现问题。

问题与建议：[GitHub Issues](https://github.com/SuperLeilei2026/city-matchmaker/issues)。
