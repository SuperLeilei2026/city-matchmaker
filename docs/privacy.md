# 资料与隐私说明

适用版本：毕业第一站 v0.6.0 本地候选。更新：2026-10-13。

## Web 体验版

Web 版不需要账号。候选模式、城市、生活取舍、宽行业、具体职业方向、兴趣、月租上限、气候红线、可选票角签名、决赛两城、原始倾向、三幕选择、首选城市和已确认任务保存在当前浏览器 `localStorage` 中。

当前本地页面没有分析统计、远端表单或模型请求。默认服务器只监听本机回环地址，并只提供项目脚本、资料和素材。共用电脑上的其他使用者可能看到尚未清除的进度；清除该站点的浏览器数据即可删除。

下载的 PNG 双城通行证包含用户在应用中主动填写或选择的城市条件、原始倾向、对局轨迹与核验任务。分享图片前应自行检查是否愿意公开这些内容。

## OctoScript 原生版

原生版通过宿主 `storage` 能力在应用隔离目录保存58字段存档，包括候选、现实条件、两城对局、首选和任务。本地候选顺序不需要模型，也不直接联网。清除本应用存档不会删除宿主可能保留的 Agent 会话。

只有用户在三幕结束后点击“让系统 Agent 找关键一问”，应用才向宿主发送当前决策上下文：

- 资料版本、左右城市 ID 与名称；
- 原始倾向和三幕选择；
- 宽行业、具体职业方向、兴趣、预算与气候红线；
- 两城约束状态、假设审计、本地问题和本地任务。

请求不需要姓名、学校、年龄、联系方式或模型密钥。原始倾向和具体职业方向会原样进入请求，因此不应填写姓名、公司机密、联系方式、密钥或其他敏感内容。宿主及所配置模型服务决定请求与响应的进一步处理，应同时查看其隐私政策。

模型回复先作为待确认问题与任务显示。它不能修改排名、两城、投票或首选；只有用户点击“加入核验清单”后，结构化任务才写入本应用存档。失败、格式错误、过期、换城、超时或取消都会回到本地规则。

代码仍保留历史城市详情 `CM1` 偏好修订兼容层及其安全回归；v0.6 主路径使用 `DQ1` 决胜提问。参考 `card-host` 没有模型服务，临时注入只验证协议边界，不属于真实模型调用。

## 数据和外部链接

城市数据与租金基准随包提供。它们是公开城市级资料，不包含个人房源。打开 GitHub 或来源链接后，相应网站可能记录访问。提交 Issue 或测试记录时请使用合成资料，不要上传真实个人档案、Agent 输入、密钥或他人隐私。
