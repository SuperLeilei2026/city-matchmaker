## 修复后的专项回归

1. **空资料、两轮均跳过：通过。** 首轮和最终结果都显示资料不足，并点明六城暂时分不出先后；没有把字母顺序的第一城说成唯一更适合。
2. **同分标签：通过。** 最终列表显示“并列候选”“现有资料分不出先后”，不再显示“首选候选”。
3. **相处标签说明：通过。** 页面明确 MBTI、星座与相处标签不参与本轮排序，不再承诺稍后一定确认。
4. **资料页签：通过。** “认识你／相处方式／工作与生活”三个页签均可点击切换。
5. **320px 布局：通过。** 三张资料页和空资料结果页的文档宽度均为 320px，没有横向溢出；已检查结果截图。窄屏上部分长标签会换行，未遮挡控件。

本轮回归没有发现阻断上述流程的新缺陷。空资料结果仍可以生成探索车票；页面已明确这只是介绍起点，不能作为有依据的唯一城市结论。
