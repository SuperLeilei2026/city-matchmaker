# Web 体验验收记录

日期：2026-10-03。对象：Joy City v0.3.0 本地 Web 工作版，默认验收地址 `http://127.0.0.1:4319`，可用 `APP_URL` 覆盖。测试使用独立 Playwright Chromium 上下文及合成资料，不读取或修改用户日常浏览器资料。

最终 [结果文件](../qa/browser-smoke-result.json) 为 `passed: true`，记录 10 组流程、0 个页面错误、0 次远端资料请求。两处发现的问题修复后已重跑通过，包括迁移备份写入失败时的保护、重新开始后仍询问所选反馈维度。最终 Node 测试 41 项通过；静态服务测试需要允许本机端口监听。

## 已实际操作通过的 10 组流程

| 验收项 | 操作与结果 |
| --- | --- |
| 场景→画像→介绍→反馈→结果 | 填写合成资料、五个场景答案及住房通勤条件，得到五行可编辑画像，明确确认后才介绍城市；反馈将恢复方式改为安静，其他答案保留。当前样例反馈前后均为上海，改答案不保证换城市。 |
| 猫狗观察角度 | 切换猫狗后，五维答案、已排除城市和住房预算保持不变；介绍角度变化不等于替用户改偏好。 |
| 刷新恢复 | 结果页刷新后恢复当前轮次和资料，不重新编造画像。 |
| PNG 与来源 | 实际生成、下载分享 PNG，来源弹窗提供城市原始资料链接。分享弹窗未出现合成院校；没有在本次 UI 测试中逐个重访外部来源。 |
| 390px／320px | 两种视口下结果页无水平溢出；320px 资料界面也检查了宽度与截图。此项是浏览器模拟尺寸，不是实体手机验收。 |
| 明确拒绝保留 | 拒绝首轮城市后，该城不出现在候选列表；返回修改昵称等资料，不会清空原拒绝与反馈。 |
| 旧存档迁移 | v1 资料迁移后保留猫狗选择及明确排除，五个新维度全部设为未知；即使备份因存储额度写入失败也能完成迁移，不从旧兴趣猜答案。 |
| 重新开始后的反馈 | 新一轮仍会询问用户所选反馈维度，不沿用上一轮的问答进度跳过问题。 |
| 清除 | 确认清除后，同时删除现行资料键与迁移备份，避免恢复已经清除的旧档案。 |
| 空画像 | 跳过场景后仍明确显示资料不足；能够继续探索并结束流程，不称为唯一适合城市。 |

运行期间页面请求仅来自本机服务或本机 blob URL；这证明该次流程没有资料外发，不能自动覆盖尚未测试的未来功能。浏览器没有调用真实模型，也没有验证 OctoSense 原生、App Hub 或现实推荐效果。
