## 当前仍待完成：真实模型成功链路

本应用尚无真实模型成功返回的验收记录。当前 card-host 不提供 octos 服务；这验证了失败处理，并不是调用代码失败的充分证据，也不是模型成功证据。

完整验收需要：在独立 OctoSense Shell 中配置可用 provider，经宿主授权请求真实模型，核对返回提案，确认后检查偏好、排序、存档与恢复。不得借用旧项目或模拟 provider 的记录。密钥只能进入宿主模型设置，不进入源码、视频、截图或提交材料。

配置与精确环境记录见 [runtime-lock.md](runtime-lock.md)。完成后应补本应用的脱敏实际记录与演示，再更新本页；当前不宣称全部参赛内容已达标。

## 数据与个人资料边界

- 城市特征是人工整理，不是统一口径的实测排名；城市人格属于创作表达。
- MBTI、星座、学校、年龄与欣赏的人格不产生城市分数。预算缺少可比较房源数据时，只列待核验事项。
- Web 资料保存在本机，不向模型发送；分享不含昵称、年龄、院校、预算或欣赏对象信息。
- 原生调用发送自由反馈和匹配所需资料，可能含预算；不自动附带结构化身份档案。自由反馈可能包含用户主动输入的隐私，发送前需自行核对。
- 所有公开验收使用合成资料。详见 [隐私说明](privacy.md)。
