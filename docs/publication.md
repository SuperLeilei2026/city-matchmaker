## 当前提供什么

- **源码与本地 Web 试玩。** 从仓库根目录运行 `node serve.mjs`，再打开该服务输出的本地地址。没有公开在线 Demo；本机回环地址不能作为给其他人使用的试玩链接。
- **OctoScript 参赛包。** `bundle/` 内含原生实现、清单、素材与真实 card-host 截图。
- **可复现的匹配测试。** `node --test tests/*.test.mjs`；已记录 25 项通过、0 失败、0 跳过。
- **数据与依据。** 六座城市、16 条公开来源，以及人工分档和未知项说明，见 [城市资料](data-sources.md)。

## 数据与个人资料边界

- 城市特征是根据公开资料进行的人工整理，不是统一口径的城市实测排名。未知项保留未知。
- MBTI、星座、学校、年龄与欣赏的人格不产生城市分数。文学化的“城市人格”也不代表居民的共同性格。
- 预算没有对应房源数据时，仅提示核验；产业存在不等于有适合某位毕业生的岗位；全市设施不等于从未来住处可达。
- 当前 Web 表单数据保存在使用者自己的浏览器，不上传到模型服务。分享内容默认排除昵称、年龄、院校、预算和欣赏的人的信息。
- 仓库中的验收流程与截图使用合成资料，不包含真实用户填写记录。
