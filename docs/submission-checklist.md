## 复现环境

- Web 产品本身：Node.js 20+，现代浏览器；无第三方运行依赖、无构建步骤、无需 API Key。实际验收为 macOS 上 Chromium，模拟窄屏不等于实体手机验证。
- 录屏工具：Playwright + Chromium、ffmpeg，另需可显示中文的字体；它们是制作材料的依赖，不是产品运行依赖。脚本用独立浏览器配置，不读取或清除用户日常浏览器资料。
- 原生：Apple silicon macOS 与文档注明的 OctoSense / Makepad 工具。其他平台与升级后的宿主状态以最新原生验收记录为准。

## 提交时的最后核对

- 最终版本能按仓库说明从干净目录启动，材料链接可以打开。
- 演示文件可播放，时长为2–3分钟，镜头是实际操作，标明版本与 Web/原生边界。
- 新材料已随最终提交发布或提供稳定可访问链接；本地文件存在不等于公开仓库已经包含。
- 录屏中没有密钥、真实用户档案或未经允许的账号数据。
- 所有“已完成”陈述都能找到对应结果；未验证的模型、平台和现实效果继续保留限制。
