# 真人试玩记录

本目录只保存经参与者同意的匿名记录。小陈、小雷目前在自动测试中是合成回归档案，不等于真人试玩已完成。

每次复制 `template.md`，文件名使用日期和匿名编号，例如 `2026-10-15-p01.md`。不要记录姓名、联系方式、公司内部信息、病历或模型/API 密钥。截图需确认没有个人信息后再加入仓库。

完成两位试玩后，汇总以下三项，不计算“推荐准确率”：

- 是否能说清一条自己依赖的假设；
- 是否发现至少一个此前没意识到的信息缺口；
- 是否能说出下一步现实核验动作。

操作脚本见 [docs/user-test-script.md](../../docs/user-test-script.md)。
