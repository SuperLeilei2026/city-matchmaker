# 本地 bundle review 回答

日期：2026-10-14。对象：`leilei-city-matchmaker 0.6.0` 最终候选。以下是作者回答，不是外部审核结论；公开提交仍需对冻结 Tag 与 release pack 复核。

1. **名称与功能是否一致？** 是。“毕业第一站”帮助毕业生把2–4座现实候选或内部初筛候选放入双城决策流程。用户亲选两城，完成工作、日常与落地三幕，审计原始倾向，最后选择先验证城市并生成双城通行证。应用不展示总相合指数，也不预测幸福、录取、薪资或 WLB。
2. **平台与类别是否合适？** `lifestyle`；已在 Apple silicon macOS 的真实 `card-host` 验证。五张 listing 截图来自该宿主。尚未声称 Android、HarmonyOS、其他桌面平台或实体手机通过。
3. **权限是否必要？** `storage` 保存本机候选、现实条件、对局、首选和核验任务。`octos.session.open`、`octos.turn.start`、`octos.turn.interrupt` 只用于用户主动请求或取消决胜提问。`network.hosts=[]`，城市与租金资料随包提供，模型密钥只由宿主管理。请求包含当前两城、原始倾向、三幕和现实条件，不需要姓名、学校、年龄或联系方式。
4. **是否模仿系统界面或第三方作品？** 否。深蓝工业车站、冷青/洋红双轨、信号黄与通行证是原创表达，不使用《双城之战》的角色、标志或具体画面，也不伪装授权、登录、支付或系统通知。
5. **源码中是否含对助手的指令？** 有。主路径 `request_decision_agent` 要求一行七段 `DQ1`。应用验证请求、资料版本、两城 ID、对局状态、维度、长度和换行。模型只能提出一个问题和一项任务；不能改排序、投票或首选城市。任务由用户点击确认后才保存。历史 `CM1` 兼容层也保留白名单与确认保护。测试注入只发生在临时包副本。
6. **是否有辱骂、歧视或针对个人的推断？** 无。MBTI、星座、学校、年龄和收藏行为不评分。城市资料描述有限产业、生活资源、租金和气候线索，不评价居民共同性格。资料缺失显示为未知，不解释成城市较差或红线已通过。
7. **路线与验证？** `human-review`。正式 v0.6 范围的69项 Node、12项真实原生双城流程、2项生产 Agent 回退和38项临时响应协议检查通过。另有43项未纳入发布的 v3 探索测试在工作区通过，不作为 v0.6 交付证据。`hub check bundle --allow-unsigned` 通过只代表本地包格式。最终签名包另在完整 Shell 中完成一次 MiniMax-M3 调用、任务确认、首城选择和重启恢复；Kimi、故障切换、目标用户满意度与移动端仍未验证。
